# Как работать с репозиторием

Этот репозиторий объединяет исходники сайта-портфолио и учебные работы. Чтобы сохранить работоспособность сайта и не потерять учебные материалы, придерживайся следующих правил.

## Где что находится

- `src/docs/` — исходные Markdown-страницы сайта.
- `src/docs/assets/` — изображения и пользовательские стили.
- `src/mkdocs.yml` — конфигурация MkDocs Material и навигация.
- `.github/workflows/deploy.yaml` — автоматическая сборка и публикация.
- `1_semestr/`, `2_semestr/` — учебные работы по семестрам.
- `docs/` в корне — **сгенерированный сайт для GitHub Pages**. Не редактируй HTML вручную: он перезаписывается при сборке.

## Локальный запуск сайта

Из корня репозитория:

```bash
python -m venv .venv
```

Активируй окружение:

- Windows PowerShell: `.\.venv\Scripts\Activate.ps1`
- Linux / macOS: `source .venv/bin/activate`

Установи зависимости и запусти сайт:

```bash
python -m pip install -r requirements.txt
cd src
mkdocs serve -f mkdocs.yml
```

Открой локальный адрес, который напечатает MkDocs (обычно `http://127.0.0.1:8000/`).

## Проверка перед публикацией

Из каталога `src/` выполни:

```bash
mkdocs build --clean -d ../site-preview
```

Успешная сборка должна завершиться без ошибок. Папка `site-preview/` используется только для локальной проверки и не нужна в Git.

## Как внести изменение

1. Создай отдельную ветку для заметного изменения.
2. Редактируй исходные Markdown-файлы, CSS или конфигурацию — в зависимости от задачи.
3. Не перемещай каталоги с учебными работами без проверки ссылок и требований заданий.
4. Перед отправкой изменений проверь сборку командой выше.
5. После push в `main` GitHub Actions собирает и публикует сайт автоматически.

## Важные ограничения

- Не меняй пути `src/mkdocs.yml`, `src/docs/` и workflow без необходимости: на них завязана публикация.
- Не добавляй секреты, токены, пароли и файлы окружения в репозиторий.
- Не добавляй результат локальной сборки `site-preview/`.
- Перед изменением зависимостей в `requirements.txt` учитывай, что там есть пакеты не только для сайта, но и для учебных проектов.
