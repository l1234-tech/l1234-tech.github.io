# :material-server: ML-сервис

> :material-language-python: **Python** · :material-web: **FastAPI** · :material-sync: **CI/CD**

## О проекте

Учебный проект: разработка backend-сервиса на **FastAPI** для загрузки ML-моделей и получения предсказаний.

## Возможности

-   :material-check-circle: **Валидация данных** — проверка входных данных перед предсказанием
-   :material-alert-circle: **Обработка ошибок** — корректные ответы при сбоях
-   :material-note-text: **Логирование** — запись событий сервиса
-   :material-sync: **CI/CD в SourceCraft** — автоматические проверки и тестирование

## Технологии

| Категория | Технологии |
|-----------|-----------|
| Backend | Python, FastAPI |
| Тестирование | pytest |
| CI/CD | SourceCraft |
