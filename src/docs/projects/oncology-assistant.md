# :material-medical-bag: AI-ассистент для онкологов

> :material-language-python: **Python** · :material-database: **БД** · :material-robot: **AI**  
> Проект разработан на хакатоне [«Цифровое здоровье»](../hackathons/digital-health.md)

## О проекте

Прототип **AI-ассистента для врачей-онкологов и исследователей**. В основе — работа с медицинскими данными и помощь в исследовательских задачах.

## Личный вклад

-   :material-check-circle: **Backend-разработка** — серверная часть приложения
-   :material-check-circle: **Работа с базой данных** — хранение и обработка данных
-   :material-check-circle: **Оркестрация компонентов** — связывание частей системы в единое целое

## Технологии

| Backend | Python |
